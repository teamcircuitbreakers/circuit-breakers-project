Calculation notes

Each summary is calculated from stored sensor readings

01Means and ranges

Arithmetic average, minimum, and maximum over the selected period.

02Humidity bands

Each reading is counted once in the displayed reference ranges.

03Variability and change

Population standard deviation uses the latest 24-hour readings. Hour-to-hour change compares means in two adjacent 60-minute windows when each has at least three readings.

04Correlation

Pearson’s r uses paired readings to describe linear association; it does not imply causation.
